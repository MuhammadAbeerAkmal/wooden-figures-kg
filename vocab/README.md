# Vendored vocabulary

`CIDOC_CRM_v7.1.3.rdf` is the official RDFS implementation of CIDOC-CRM 7.1.3,
downloaded unchanged from <https://cidoc-crm.org/rdfs/7.1.3/CIDOC_CRM_v7.1.3.rdf>.

It is kept here so that a unit test can check that every CIDOC-CRM class and
property used by this project really exists in the official release
(`apps/api/src/rdf/crm-terms.spec.ts`).

CIDOC-CRM is published by the CIDOC CRM Special Interest Group under the
Creative Commons Attribution 4.0 licence. The MIT licence of this repository
does not apply to that file.
